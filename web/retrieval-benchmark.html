How to form the first query

All strategies see the same preceding conversation and question and search the same index. The raw row uses the conversation and question as written. The routed row uses Qwen 3.5 9B, the provisional best-performing model in the measured evidence-aware routing comparison. It decides whether to search and writes the query in one model call; separate router/query combinations were not measured. Other router models are omitted so their routing accuracy does not confound this retrieval view. Always-inferred rows are query-generation controls that search on every question and do not use routing.

Follow up after seeing evidence

This is a different dataset and task from first-query formulation above. The displayed follow-up run fixes routing to Qwen 3.5 9B, the provisional best-performing model in the measured evidence-aware routing comparison. It sees the first six passages and can request a second search with an inferred query; reciprocal-rank fusion combines the results. Raw retrieval remains the baseline, and other router models are omitted so route quality stays fixed. The same 9B model makes the decision and writes the follow-up query, so the table measures their combined effect. This is an offline experiment, not the ordinary question path.

Separate experiment: graph expansion on the same test questions

The offline replay adds up to three existing relationship passages to the displayed Qwen 3.5 9B adaptive ranking. It is not another query-model configuration and is not enabled by default. On this visible test split, 9B recall@6 changed 0.478 → 0.622; the expansion also displaced labeled evidence in some cases. Mean added expansion time was 0.052 ms, excluding the original searches, model inference, I/O and graph construction; it is not end-to-end time. The method was tuned with visible examples and test output, so this figure is exploratory. Inspect the 9B output.
