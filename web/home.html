CDM RAG is a local assistant for Microsoft Common Data Model schemas. Ask a question in everyday language, get a concise answer grounded in the catalog, and follow its citations back to the source definitions.

Ask a question → Explore the graph

This demo includes a pinned Retail Banking and applicationCommon subset of CDM; it is not the complete Microsoft CDM catalog.

Why it helps

Schemas are connected, not just lists of fields.

Finding a field is only part of understanding a data model. The useful context may be in the entity that owns it, a relationship that points elsewhere, or a trait that describes how the schema should be interpreted.

CDM RAG brings those definitions into a question-and-answer flow and keeps the source evidence close, so people can explore unfamiliar schema areas and check the answer instead of taking it on trust.

Useful when you need to understand an unfamiliar CDM object, trace a relationship, compare schema concepts, or check which definition supports an answer.

How it works

A short path from question to evidence

The app searches a local index built from the pinned catalog, then presents the selected source passages with the answer.
