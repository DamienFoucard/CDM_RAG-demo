Routing evaluation.

Compare models on the decision to search with the original wording, rewrite the query, or avoid catalog search.

Routing is tested on its own. A separate query model can be chosen when a rewrite is needed.

Reading these results. Only the test split is scored here. Green marks the best observed value and blue the second distinct value in a column; ties share a highlight. Lower time and fewer errors are better. Counts use attempted test questions; a run may cover a subset.

The labels are a provisional routing policy, not a measurement of downstream retrieval quality. The questions are source-derived or assistant-authored, not independently reviewed or a blind holdout. The three-way questions were authored in the same session as this evaluation. Development is used for tuning, not model training.
